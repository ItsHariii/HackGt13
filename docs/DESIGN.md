# Design index

The visual design lives in the Claude Design project [`51070676-303a-487e-a16d-1ee878c848cc`](https://claude.ai/design/p/51070676-303a-487e-a16d-1ee878c848cc) (read it with DesignSync after `/design-login`). File names there predate the rename and still say ProofCart and DemoMart; in code and docs the product is **Cartel** and the test merchant is **GreatHub**. Where a design still shows "ProofCart", "DemoMart", a "PC-" id, a "DM" source icon or "Best Buy" (replaced by UPCitemdb), build it as Cartel, GreatHub, a "CT-" id, a GreatHub icon and UPCitemdb.

This index records every design file, the route it maps to, the frames it shows and what it adds beyond [TASKS.md](TASKS.md). Tokens: [`apps/web/app/cartel-tokens.css`](../apps/web/app/cartel-tokens.css) (a port of the design's `proofcart-tokens.css`).
